## Manutenção

Atualize o status quando houver evidência de implementação ou teste. Diferencie **implementado no Unity**, **APK compilado** e **validado no Quest**. Ter um modelo 3D não significa que a interação da missão está pronta.

Não há pipeline de testes no GitHub Actions configurado nesta organização. As verificações de fluxo são executadas pelo menu do Unity e precisam ter seus resultados registrados na entrega.
